# Изменения для Pull Request

## Описание изменений (Ноябрь 2025)

### Добавлена **унифицированная детекция стрелок и конусов**

**Основные изменения:**

1. **Создана библиотека `eureka_nav_lib.py`** - автономная библиотека детекции навигационных объектов:
   - Может работать без ROS2
   - Содержит все алгоритмы YOLO, PCA, фильтрации
   - Публичный API: `NavigationDetector`, `DetectionResult`
   - Методы: `detect_arrow()`, `detect_cone()`, `detect_all()`

2. **Унифицированная калибровка расстояний**:
   - `CALIBRATION_TABLE_ARROWS` - таблица калибровки для стрелок (используется ширина)
   - `CALIBRATION_TABLE_CONES` - таблица калибровки для конусов (используется высота)
   - Автоматический выбор таблицы на основе типа объекта
   - Кусочно-линейная интерполяция с экстраполяцией

3. **Рефакторинг ROS2 ноды `nav_simple_cv.py`**:
   - Упрощена до тонкой обёртки вокруг библиотеки
   - Детектирует одновременно стрелки И конусы
   - Новый формат сообщений: `name = "arrow:left"`, `"cone:none"` и т.д.
   - Переименованы топики: `arrow_detection` → `navigation_detection`

4. **Оптимизация параметров детекции**:
   - `CONF_THRESHOLD = 0.5` - порог уверенности
   - `MIN_BOX_SIZE = 2px` - минимальный размер детекции
   - Исправлена ошибка дублирования детекций из cut frame

5. **Тестирование**:
   - 88% detection rate на тестовых видео
   - 3,458 стрелок + 1,056 конусов обнаружено
   - Стабильная работа на CUDA

## Предыдущие изменения (Октябрь 2025)

### Система калибровки расстояний и углов

#### 1. Калибровка расстояний

Добавлена **система калибровки расстояний** через таблицу соответствия. Для калибровки необходимо разместить стрелку на известных расстояниях (например, 1м, 2м, 3м и т.д.), измерить ширину и высоту детекции в пикселях, и внести эти значения в таблицу `CALIBRATION_TABLE` в файле `calibration_config.py` в формате `(расстояние_м, ширина_px, высота_px)`. Система автоматически выполняет кусочно-линейную интерполяцию между заданными точками для определения расстояния до стрелки на любом промежуточном расстоянии. Диапазон калибровки настраивается параметрами `MIN_DISTANCE_M`, `MAX_DISTANCE_M` и `DISTANCE_STEP_M`. В режиме выставки можно включить отображение размеров детекции на экране (параметры `SHOW_PIXEL_WIDTH` и `SHOW_PIXEL_HEIGHT`).

#### 2. Калибровка углов (фокусное расстояние)

Добавлен параметр **`FX_PIX`** (фокусное расстояние в пикселях) для точного расчета горизонтальных углов. Этот параметр определяет, насколько точно система рассчитывает угол между стрелкой и центром изображения.

**⚠️ ВАЖНО:** Текущее значение `FX_PIX = 920.0` **требует проверки и калибровки**.
